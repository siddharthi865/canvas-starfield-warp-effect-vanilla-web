# Canvas Starfield Warp Effect

An interactive hyperspace-inspired starfield built with the HTML Canvas API, vanilla JavaScript, and Tailwind CSS. Stars exist at simulated depths and are projected onto a two-dimensional canvas to create the illusion of rapidly travelling through space.

## Features

- Animated starfield rendered with the Canvas API
- 3D-style depth simulation using perspective projection
- Star trails that become longer as velocity increases
- Adjustable warp-speed control
- Interactive warp boost mode
- Pause and resume controls
- Responsive star population based on viewport size
- Smooth animation using `requestAnimationFrame`
- Delta-time-based movement for more consistent animation speeds
- High-DPI canvas rendering support
- Responsive, mobile-first interface
- Reduced-motion preference support
- Accessible labels, buttons, status updates, and keyboard-friendly controls

## Tech Stack

- HTML5
- Tailwind CSS via CDN
- Custom CSS
- Vanilla JavaScript
- HTML Canvas API
- `requestAnimationFrame`

No frameworks, build tools, or JavaScript libraries are required.
